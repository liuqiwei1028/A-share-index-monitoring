# A股指标监测

本地静态站点，双击 `index.html` 即可打开（图表库与数据均在本地，不依赖网络）。
用于**总仓位判断**，不产生个股买卖信号。

每个交易日 16:00 由 Windows 计划任务「A股指标收盘更新」自动更新。

## 目录

```
指标跟踪/
  index.html            站点（静态，交互为图表缩放与时间范围切换）
  update.cmd            计划任务入口（纯 ASCII，避免 cmd 按 GBK 解析出错）
  vendor/echarts.min.js 本地图表库
  data/indicators.js    站点读取的数据（window.IND_DATA）
  data/indicators.json  同内容 JSON，便于其他脚本复用
  data/daily.csv        每日一行汇总，Excel / 其他脚本可直接读
  data/ma_cache.json    每只个股最近 250 个收盘价（算 P20/P60/P250 用，约 7MB）
  data/pcr_cache.json   沪深300 股指期权 PCR 日度缓存
  data/ho_cache.json    上证50 股指期权 PCR 日度缓存
  data/update.log       每次运行日志（UTF-8）
  scripts/fetch.mjs     数据管道
  scripts/report.mjs    每日复盘报告（规则引擎，16:05 生成）
```

## 命令

```powershell
node scripts/fetch.mjs --daily    # 日常增量，约 16 秒（定时任务用这条）
node scripts/fetch.mjs --recalc   # 不重抓个股，仅用已存底表重算 TRIN/MCL
node scripts/fetch.mjs            # 全量重建，约 3 分钟（回补 5200 只个股日线 + 1650 天期权）
```

## 指标

| 指标 | 定义 | 频率 |
|---|---|---|
| TRIN | `(上涨家数 ÷ (平盘家数 + 下跌家数)) ÷ (上涨股成交额 ÷ 下跌股成交额)` | 日 |
| MCL | `EMA19(涨跌家数差) − EMA39(涨跌家数差)`，麦克莱伦振荡指标 | 日 |
| PCR | 沪深300（IO）与上证50（HO）股指期权认沽 ÷ 认购，含持仓量口径 | 日 |
| PCR ±2σ | 成交量 PCR 的 120 日滚动均值 ± 2 倍标准差 | 日 |
| 红盘率 | 上涨家数 ÷ 当日有成交的全 A 家数 | 日 |
| P20 / P60 / P250 | 收盘价站上 20 / 60 / 250 日均线的家数 ÷ 有足够历史数据的家数 | 日 |
| 涨停 / 跌停 | 触及涨跌幅限制的家数 | 日 |
| 股债利差 | `100/PE(沪深300) − 10年期国债收益率` | 日 |
| ETF 占比 | 四只头部 ETF 净资产合计 ÷ 沪深300 流通市值 | 季 |
| ETF 放量 | 成交额前 50 的股票型 ETF：放量倍数（÷ 前 20 日均额）与成交额分位 | 日 |
| ETF 份额 | 沪深300 / 创业板 / 科创板 主要 ETF 的场内份额（成交量÷换手率反推，误差约 0.5%） | 日 |
| 每日复盘 | 汇总当日指标 + 创业板/科创板结构 + CPO 持仓表现，给出走势判断 | 日 |
| 创业板/红利 | 创业板指 ÷ 中证红利指数，衡量成长相对红利的贵贱 | 日 |
| 美债 10Y | 美国 10 年期国债收益率 | 日 |
| 布伦特 / 黄金 | 新浪外盘期货连续合约（OIL / GC） | 日 |

四只 ETF：华泰柏瑞 510300、华夏 510330、嘉实 159919、易方达 510310。

## 口径

- **样本**：沪深两市全体 A 股，剔除北交所；停牌（成交额 0）与上市不足 60 个交易日的新股不计入。
- **覆盖度过滤**：单日参与统计的个股少于 2000 只视为覆盖不全，整日剔除。长期停牌股的稀疏 K 线会把序列拖到 2018 年，那几天只有 1–2 只股票参与，会严重扭曲 MCL 的 EMA39。
- **TRIN 用成交额**而非股数；平盘家数计入分母。个股收益率用前复权收盘价，避免除权跳空被误算成下跌。页面只展示当日实际值与分项（涨跌家数、涨跌额、两个占比），不再画 20 日均线；仓位打分内部仍用均线分位以过滤单日噪音。
- **MCL** 前 39 个交易日 EMA 未收敛，不计入。
- **P20/P60/P250** 的均线含当日收盘价；分母取当日有足够历史数据的家数，故三个指标的分母略有差异。
- **涨跌停** 按板块阈值判定：主板 ±9.8%、双创 ±19.5%。ST（±5%）与新股上市初期未单独处理，因此涨停家数会略偏低。
- **PCR** 只统计 IO（沪深300股指期权）合约，中金所日行情 CSV 中按 `IO+月份-C/P-行权价` 解析。
- **上证50 PCR** 取 HO（上证50股指期权，中金所），与 50ETF 期权同标的指数但历史完整，可回溯到 2022-12-19。曾试过 510050 的 ETF 期权：上交所无公开日频聚合文件，且两家免费源都在合约到期后删除数据，历史无法回算，故改用 HO。
- **±2σ 轨道** 用成交量 PCR 的 120 日滚动均值与标准差计算，窗口随日期滚动；轨道目前只画在沪深300 上，避免四条虚线互相打架。
- **ETF 分子**取季报期末净资产；**分母**以最新成分为锚、按指数涨跌回推历史，属近似，只适合看趋势与分位。
- **股债利差**的 PE 为中证指数官方静态口径；因 10 年期国债收益率长期下移，固定阈值已失效，页面只用分位。

## 仓位参考

```
情绪分 = (TRIN均线分位 + PCR分位 + (100 − MCL分位)) / 3    # 三者都换算成「恐惧程度」
综合分 = 0.5 × 利差分位 + 0.5 × 情绪分
目标仓位 = 30% + 综合分 × 0.6                              # 即 30%–90%
若沪深300 收盘 < 200 日均线，仓位上限压到 60%
```

红盘率、P20/P60/P250、涨跌停目前只做展示，未纳入打分——它们与 TRIN/MCL 高度同源。
ETF 占比为季度频率，同样不参与打分，只作资金面参考。

## ETF 放量监控

取成交额前 50 的股票型 ETF（剔除货币/债券/商品），逐只取日线算：

- **放量倍数** = 当日成交额 ÷ 前 20 日均额
- **成交额分位** = 当日成交额在自身近 250 个交易日中的位置
- **池子合计成交额** = 这 50 只逐日加总

放量本身不分好坏：下跌放量多为承接或止损，上涨放量才是增量资金。参考站点的「净份额变动 / 净申赎金额」需要日频份额历史，公开源没有，暂时不做；四只沪深300ETF 的日度规模已从 2026-10-28 起累积，攒够后可补上申赎口径。

## 定时任务

两个计划任务，都调用 `update.cmd`（允许电池供电时启动、错过则补跑）：

| 任务 | 时间 | 作用 |
|---|---|---|
| A股指标收盘更新 | 周一至周五 16:00 | 出当日数据 |
| A股指标数据回填 | 周一至周五 21:00 | 用官方估值覆盖推算值 |
| A股指标盘中前瞻 | 周一至周五 14:30 | 只读快照算当日 TRIN 前瞻，写 data/intraday.md，不动历史库 |

中证指数的 PE 要到傍晚才发布，16:00 拿不到当日值，因此按「上一交易日 PE × 沪深300 涨跌」推算当日 PE（页面标「推算」）。静态 PE 的盈利项在两次年报之间不变，所以这个换算与官方值几乎一致；21:00 的任务再拉官方数据覆盖。

```powershell
schtasks /Query /TN "A股指标收盘更新" /FO LIST /V   # 查看状态与上次结果
schtasks /Run   /TN "A股指标收盘更新"                 # 手动触发一次
```

非交易日脚本会自行判定（以沪深300 实时行情的时间戳为准，而非中证指数的发布进度）并跳过，不会写入脏数据。

## 环境注意

- 本机 PowerShell / curl 的 HTTPS 因证书凭据失败（`SEC_E_NO_CREDENTIALS`），**HTTPS 抓取必须走 Node**。
- Node 需要 `dns.setDefaultResultOrder('ipv4first')`，否则会走 IPv6 直连超时（脚本已内置）。
- 东财 `push2` 系列接口必须带 `Referer: http://quote.eastmoney.com/`，否则连接会被重置（脚本已内置）。

## 已知局限

1. ETF 规模季度披露，日度序列从 2026-10-28 起才累积。
2. 沪深300 流通市值历史为回推近似，绝对水平不宜对外引用。
3. 涨停家数因 ST 与新股处理不完整而略偏低，早于 2020-08 的 P250 不可用（历史不足 250 日）。
5. 上证50 用的是 HO 股指期权而非 50ETF 期权（后者无公开历史）；两者标的指数相同，但成交结构略有差异。
4. 六个日频指标彼此相关，同时偏高只说明「同一个方向上有六份同源证据」，不是六个独立信号。
